# Government of Canada data sources: candidates for review

Researched Nov 1, 2026 from official pages and search results. Mark each row **Y / N / Later** in the last column, then I'll fold your picks into `BRIEF.md`.

**How to read this:** "Verified" means I found it on a Government of Canada or agency page or in search results this session. "Unverified" means I'm relying on a third-party page or general knowledge, so check it before building. Items under "My suggestion" are my opinion, not a finding.

---

## 1. Where the data lives (access layers)

Nearly every source below has a documented download or API route, so scraping web pages should rarely be necessary.


| Layer                                                            | What it gives you                                                          | Access                                                                                                                                                              | Status                                                                                                                                                                                     |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Statistics Canada, Web Data Service (WDS)**                    | Time series and table metadata, released each business day                 | REST, JSON. Methods include `getCubeMetadata`, `getDataFromVectorsAndLatestNPeriods`, `getBulkVectorDataByRange`, `getFullTableDownloadCSV`, `getChangedSeriesList` | Verified (method names). **Request limits: not confirmed**; I could not open the user guide. An R package's docs say batches over 300 coordinates must be split (third-party, unverified). |
| **Statistics Canada, full-table CSV**                            | A whole table as a zipped CSV with metadata                                | URL pattern from StatCan's own tips page: `https://www150.statcan.gc.ca/n1/en/tbl/csv/<8-digit-table-id>-eng.zip` (e.g. `14100287`)                                 | Verified                                                                                                                                                                                   |
| **Statistics Canada, Delta File**                                | One file with everything released each business day                        | Download                                                                                                                                                            | Verified (described as the preferred way to get large updates)                                                                                                                             |
| **Statistics Canada, SDMX REST**                                 | Structured series, 2021 Census Profile by geography and characteristic     | REST (SDMX)                                                                                                                                                         | Verified                                                                                                                                                                                   |
| **Statistics Canada, Indicators JSON and release schedule**      | Headline indicators from The Daily; release dates incl. future ones        | JSON files (`ind-all.json`, `ind-econ.json`, `schedule-key_indicators-eng.json`)                                                                                    | Verified. Useful for knowing *when* to refresh.                                                                                                                                            |
| **Open Government Portal (open.canada.ca)**                      | Federal catalogue, plus some provincial and municipal data                 | CKAN API, read-only, **GET only**, no key for reads (e.g. `.../data/en/api/3/action/package_search?q=...`)                                                          | Verified                                                                                                                                                                                   |
| **Bank of Canada, Valet API**                                    | Exchange rates, interest rates, other financial series                     | REST. **No registration or key**, free. Base `https://www.bankofcanada.ca/valet/`                                                                                   | Verified. No numeric rate limit published; guidance is to cache daily data, increase request rates gradually and back off on failures. Read the Bank's terms of use for attribution.       |
| **Environment and Climate Change Canada, MSC GeoMet / Datamart** | Weather, climate normals, daily and monthly observations, hydrometric data | OGC API (`api.weather.gc.ca`), WMS/WCS, CSV on Datamart. Anonymous and free                                                                                         | Verified. Climate-station coverage in the map tools is a subset. ECCC has its own end-user licence.                                                                                        |

## 4. Things I could not verify

- **StatCan WDS request limits.** The user guide page was not reachable from my session. Build in throttling and caching, and confirm limits there.
- **Table IDs for merchandise trade, retail, housing price indexes, wages.** I did not confirm these. Search the StatCan data catalogue by subject.
- **Official API for CMHC.** I found none, only the portal and downloadable tables.
- **Current release dates and last-updated times** for each dataset. Use the StatCan release-schedule JSON and each portal record.
- **Bank of Canada terms of use** and any attribution requirement.
- **Portal totals.** I did not count how many datasets the portal holds.

## 5. My suggestion (opinion, not a finding)

For a first end-to-end slice, one price index (row 1) plus one Bank of Canada series (row 6) gives you two different access methods, two licences to attribute, and a natural story (inflation and rates) without needing maps or large files. Adding labour (row 2) or population (row 4) afterward extends the same StatCan code path.
